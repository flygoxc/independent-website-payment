IBAN、BIC、SWIFT Code——这些编号都是什么意思？

Day 12 / 100 · 阅读约 4 分钟

你给外地朋友打电话，先拨区号（010、021），再拨手机号。少了区号，电话打到别的城市；少了号码，根本打不通。银行账户跨国转账也一样：既要"区号"找对银行，又要"号码"找对账户，漏一个，钱就到不了。

今天把这些号码逐个拆开看明白。

三个号码分别是什么

跨境转账时，对方可能会问你要一串英文缩写：BIC、SWIFT Code、IBAN。别被绕晕，它们其实就三类：

1. SWIFT Code / BIC（银行识别码，Bank Identifier Code，就是识别"哪家银行"的代码）

  • 通常是 8 或 11 位字母数字，比如 HSBCHKHHXXX。
  • 它的作用＝区号：告诉系统"这笔钱要送到哪家银行"。
  • 注意：SWIFT Code 和 BIC 是同一个东西，只是叫法不同，就像"土豆"和"马铃薯"。

2. IBAN（国际银行账号，International Bank Account Number，国际统一的银行账号格式）

  • 通常是字母+数字组成的串，比如欧洲国家常见。
  • 它的作用＝手机号：在区号基础上精确到"哪个客户账户"。
  • 注意：不是所有国家都用 IBAN。欧洲、中东许多国家强制要求，美国、中国内地、中国香港地区一般不用 IBAN，而是用普通账号。所以对方要 IBAN，你就提供 IBAN；对方要账号，就提供账号。

3. 账号（Account Number）

  • 你在银行开的那个账户号码，作用同样＝手机号，只是格式不统一。

三个号码的配合，就是一套"国际转账地址"：

号码好比作用谁提供
SWIFT Code / BIC区号锁定银行银行官网可查
IBAN标准格式手机号锁定账户（部分地区）银行账单上
账号普通手机号锁定账户你开户后获得

再补一个高频词：收款行（Beneficiary Bank，就是收钱的账户所在的那家银行）。填汇款单时，"Beneficiary"（收款人）一栏要填收款人名称、账号、开户行 BIC 和开户行地址，这四样齐全，汇款才不容易被退。

实操小贴士

  • 把收款信息做成"名片"：把公司的 BIC、账号、收款行名和地址整理成一张标准图/文本，客户要付款时直接发，避免每次现找、现抄错。
  • 收到欧洲客户付款，注意 IBAN：欧洲客户付款常要 IBAN；香港账户通常没有 IBAN，可跟银行确认是否提供等效信息，或建议客户按 SWIFT 方式付款。
  • 信息要一字不差：BIC 里一个字母错、账号少一位，钱就可能卡在中转行。付款前对照银行账单逐字核对，实在不放心，可以先转一笔小额测试。

风险提示

  • 收款信息（尤其 BIC、账号）属于敏感信息，只在真实交易场景提供给对方，谨防被骗子利用（比如骗子让你把货款转到"改过的"账号）。
  • 如果有人以"账号填错需要先交钱解冻"为由让你追加转账，一律是诈骗。
  • 开户时银行会发给你完整的收款信息清单，一切以你开户行的官方资料为准，不要相信第三方提供的"你的账号信息"。
一句话总结
BIC 是"区号"（找银行），账号或 IBAN 是"手机号"（找账户）——跨境收款就是把这两个号填对，像写一封地址完整的国际信件。 （预告：信息传到了、号码填对了，钱是怎么"对账"又怎么"到账"的？明天讲清算和结算。）
